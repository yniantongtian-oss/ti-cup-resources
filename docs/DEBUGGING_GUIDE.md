# 硬件调试指南 | Hardware Debugging Guide

## 基本原则

1. 先让电源和主电路工作正常
2. 再逐步添加功能模块
3. 保护电路优先
4. 多用示波器观察波形

## 常见问题排查

- PWM 无输出 → 检查定时器配置和引脚复用
- ADC 采样不准 → 先确认参考是 VDDA、内部基准还是外部基准，再查采样时间
- 保护误触发 → 检查阈值设置和滤波
- RS-485 偶发 CRC 错误 → 确认 DE 在 UART TC 之后才释放，见 [Modbus 指南](MODBUS_DEBUGGING_GUIDE.md)

## 推荐调试流程

1. 最小系统测试
2. 外设单独测试
3. 整体联调
4. 极限条件测试
